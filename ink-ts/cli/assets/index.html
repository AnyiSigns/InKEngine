ink-ts cli serve（静态托管占位）

serve 形态为 web 前端（S8 @ink-ts/web）预留的连接面。占位页说明通道契约：

  • GET /health — 健康检查
  • POST /rpc — JSON-RPC 2.0（host.ping / host.info / host bridge 方法面）， 鉴权 Authorization: Bearer <token>（listen 行输出）
  • WS /ws?token=<token> — 事件订阅：events.*（引擎事件）与 state.*（serve/回合状态）

web 迁入（S8/T6）后由 cli 托管 Vite 构建静态产物，此处即产品 UI 挂载点。
