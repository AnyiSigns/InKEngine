# Python 零基础入门方案

## 子任务1：环境搭建与验证指南
1. 访问 python.org 下载 Python 3.11+ 安装包
2. 安装时勾选 "Add Python to PATH"
3. 安装完成后，打开 CMD 输入 `python --version` 验证版本
4. 输入 `python` 进入交互模式，输入 `print("Hello World")` 测试运行

## 子任务2：基础语法知识点梳理
- **变量与类型**：整数、浮点数、字符串、布尔值
- **数据结构**：列表（增删改查）、字典（键值对）
- **控制流**：if/elif/else 条件判断、for/while 循环
- **函数**：def 定义、参数传递、return 返回值
- **文件操作**：open() 读写文本文件
- **异常处理**：try/except 捕获错误

## 子任务3：入门小项目方案
**项目**：简易待办事项清单（To-Do List）
- 功能：添加任务、查看所有任务、标记完成、删除任务
- 技术点：列表存储、函数封装、用户输入循环、条件判断
- 扩展：持久化存储到 txt 文件

## 300字学习计划汇总
**第1天**：完成 Python 环境搭建，掌握交互模式与脚本运行方式，成功输出首行代码。
**第2-3天**：系统学习变量、条件判断与循环，每日完成50行以上代码练习，重点理解列表与字典操作。
**第4-5天**：深入学习函数定义与文件读写，理解代码复用逻辑。
**第6-7天**：实战开发待办事项清单项目，实现增删查改功能，尝试将数据保存到本地文件。
**每日建议**：理论学习1小时+编码实践1小时，遇到问题善用官方文档与社区搜索。坚持两周即可掌握Python基础，建立编程思维。
