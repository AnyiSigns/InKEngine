## 一周 Python 零基础入门计划（每天约 1-1.5 小时）

**第 1 天：环境搭建与第一行代码**
- 安装 Python 和 VS Code（或 IDLE）
- 理解 print()、变量命名、注释
- 练习：打印自我介绍、计算圆面积

**第 2 天：核心数据类型**
- 字符串（拼接、格式化 f-string）
- 数字（整数、浮点数、基本运算）
- type() 函数查看类型
- 练习：制作个人名片信息卡

**第 3 天：容器类型（上）**
- 列表：创建、增删改查、切片
- 元组：不可变特性
- 练习：管理购物清单、统计成绩

**第 4 天：逻辑控制**
- 条件判断（if/elif/else、缩进规则）
- for 循环、while 循环
- break/continue
- 练习：判断闰年、九九乘法表

**第 5 天：函数基础** ⚠️ **最容易失败的一步**
- 定义函数 def、参数、return
- 变量作用域（局部/全局）
- 练习：封装计算器功能

**第 6 天：文件与异常**
- open() 读写文本文件
- try-except 异常处理
- 练习：日记写入与读取

**第 7 天：综合项目**
- 开发「猜数字」游戏（随机数模块）
- 整合循环、条件、函数
- 调试与代码优化

---

**最容易失败的一步：第 5 天（函数）**
原因：函数涉及「抽象思维」——将具体操作打包成可复用模块，对零基础者认知跳跃较大，容易混淆参数传递和返回值。

**替代建议：**
1. **推迟法**：先跳过 return 的复杂用法，把函数当作「带名字的代码块」理解，第 6 天后再回看
2. **类比法**：用「菜谱」类比——def 定义菜名（参数=食材），return 是上菜（结果）
3. **可视化法**：用纸笔画「输入→黑盒→输出」流程图，降低抽象感
4. **最小化练习**：只写无参数的简单函数（如 def say_hello(): print('Hi')），先建立信心再增加复杂度
