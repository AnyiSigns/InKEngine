# 记忆整合仲裁（证据/缓存/策略边的裁决链）

## 优先级链（代码化，勿在别处重写）

记忆整合按固定优先级裁决，且已代码化在引擎既有实现中（本文件只做
文档化，不引入第二套裁决）：

```
缓存短路  >  边证据  >  策略边 τ 档
```

1. **缓存短路**：上下文指纹命中且未失效（模型未变、契约版本未漂移、
   证据未漂移）时，组装直接返回缓存路径——不触发算法搜索与草稿生成
   （统计 `cache_hits`）。
2. **边证据**：缓存未命中（无条目/失效/抽样绕过）时，裁决落到边证据
   评分——候选链按各边 `edge_score`（p̂ · w_n · d(t) · τ）计分排序，
   证据越强分越高（统计 `cache_misses`）。
3. **策略边 τ 档**：策略边（显式承诺）取 τ=1.0 且豁免时间衰减；经复审
   降级（失败累计超阈或域均值反超承诺）后 `policy=False`，τ 豁免移除，
   评分回落到统计档口径。

## 三处整合语义

### 缓存未命中 → 边证据接管

无缓存条目或条目失效后，组装候选的评分完全由边证据决定：同请求下，
边证据越强（成功史/样本量/时效），候选分越高。未命中路径不产生任何
缓存写入，统计 `cache_misses` 计数。

### 证据漂移 → 重组装

缓存条目携带证据快照；沉淀侧每次新证据落库后，下次组装对比快照与
当前证据（差 ≥20% 且 N≥5，或信任档变化即判漂移；N<5 不误判）。漂移
判定 → 条目失效（`cache_invalidations`）→ 本次组装走证据驱动的重组装
（候选来源为算法/草稿路径，非缓存短路）。

### 策略边复审降级

策略边声明 τ=1.0 豁免；复审钩子在失败累计 ≥ 阈值（或域证据均值反超
策略边承诺）时提请 L2 复审并把边降级为普通统计边（`policy=False` 落库，
审计留痕）——此后该边评分走统计档：τ 取信任档位、时间衰减不再豁免，
降级后评分自然回落（复审去重：降级后不再重复提请）。

## 一致性约束

- 三档裁决共用同一评分公式（`edge_score`）与同一证据存储，口径单一；
- 组装侧与沉淀侧的缓存键同源（上下文指纹），证据快照随条目往返；
- 本仲裁链的断言覆盖见 `tests/test_evidence_arbitration.py` 与
  `tests/test_fingerprint_cache.py`（漂移阈值/顶替/ε 抽样专项）。
