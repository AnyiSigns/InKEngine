## 1. 知识闸门开/关（样例库 5 条候选：3 合法 + 2 反例）

| 对照臂 | 落库 | 拦截 | 指令注入检索命中 |

| 开（三层闸门裁决） | 3 | 2 | 0 |
| 关（直落旁路） | 5 | 0 | 1 |

闸门逐条裁决（开臂）：

| 候选 | L1 | L2 | L3 | 裁决 |
|---|---|---|---|---|
| 合法规则 1（放行预期） | True | True | True | 放行 |
| 合法规则 2（放行预期） | True | True | True | 放行 |
| 合法规则 3（放行预期） | True | True | True | 放行 |
| 指令注入反例（拦截预期） | False | False | False | 拦截 |
| 声明不可加载反例（拦截预期） | False | False | False | 拦截 |

**结论**：开臂拦截 2 条反例且不误杀合法规则；关臂反例直落知识集，污染可被检索触达（注入措辞查询命中 1 条 vs 开臂 0 条）——闸门有真实保护作用，机制被需要。

## 2. 蒸馏开/关（三轮合成信号流）

| 对照臂 | 触发 | 复用优先 | 沉淀产出 | 知识增长 | 检索命中 |
|---|---|---|---|---|---|
| 开 | 3 | 1 | 2 | 2 | 1 |
| 关 | 0 | 0 | 0 | 0 | 0 |

**结论**：开臂三轮中重复 query 走复用优先（不重复蒸馏），新知识沉淀（增长 2 条）并可检索触达；关臂零触发零增长——蒸馏是知识从轨迹信号成长为可检索资产的唯一通路，机制被需要。

## 3. 调参开/关（四轮合成回合指标：高失败率 + 低分反馈 + 慢收敛）

| 对照臂 | 参数变更 | quality 权重 | 重试预算 | web 验证阈值 | 探索宽度 |
|---|---|---|---|---|---|
| 开（MetaTuner） | 12 | 0.6561 | 2 | 0.1 | 6 |
| 关（基线） | 0 | 1.0 | 1 | 0.5 | 3 |

回归保护（越界变更）：

| fixture 下限 | 变更数 | 参数保持原值 |
|---|---|---|
| weights ≥ 0.95 | 0 | True |

**结论**：开臂参数随指标自适应（低分维度降权、失败率高上调重试预算、慢收敛加宽探索），关臂恒基线；越界变更被回归样例闸门拒绝——调参在边界内收敛且防失控，机制被需要（运行时接线待产品化落地）。

## 5. 总论

- 三组对照全部存在显著可测差异（拦截/增长/参数漂移），无一机制出现「开-关无差异」的裁剪信号——闸门/蒸馏/调参继续投入，不做裁剪；
- 调参已具备完整机制件（调参器/回归/快照）但尚未接入运行时回合收尾，列为产品化接线项；
- 本次对照为离线确定性口径（stub 模型），真实模型方差下的增益留待live 评测在预算内抽样复核。
